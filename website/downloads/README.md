# APK downloads

Project creator and developer: **PolarDredd**.

`index.html` serves the downloads landing page. `mrdiy-careers.apk` is the binary downloaded by visitors.

For an authorized APK release, build and test the intended app version, confirm signing and version metadata, and copy the selected APK here. Record the source commit, version, SHA-256, and verification in the release commit or QA record. Updating source or building locally does not replace this file automatically.

Keep the landing-page links and website download buttons aligned with the APK filename. Verify the public download route after an authorized deployment.
